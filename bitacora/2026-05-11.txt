    --input  TBDs/cohort/results/cohort.h5ad \

    --input  TBDs/cohort/results/cohort_integrated.h5ad \

    --outdir TBDs/cohort/results/pseudobulk_muscat

    --decoupler-dir TBDs/cohort/results/pseudobulk_decoupler \

    --outdir        TBDs/cohort/results/pseudobulk_consensus

  Flags:    --with-scvi  --keep-outputs  --log-level DEBUG

3 BUGS PRODUCTIVOS encontrados + corregidos durante el smoke test:

  BUG 1 — decoupler v2 API
    Archivo: pipeline/scripts/integration/pseudobulk_decoupler.py
    Causa: decoupler 2.x usa dc.pp.pseudobulk (no dc.get_pseudobulk
           como en v1) y la columna de conteo de células se renombró
           a psbulk_cells (era psbulk_n_cells).
    Fix:   Llamada actualizada + búsqueda defensiva con fallback.

  BUG 2 — LIANA use_raw
    Archivo: pipeline/scripts/integration/F0c_ccc_liana_multisample.py
    Causa: Por defecto LIANA lee de adata.raw; nuestro cohort no
           inicializa .raw (counts viven en layers['counts']).
    Fix:   use_raw=False explícito → LIANA usa adata.X (log1p).

  BUG 3 — LIANA resource vs panel size
    Archivo: pipeline/scripts/integration/F0c_ccc_liana_multisample.py
    Causa: LIANA rechaza el run si >98% del recurso L-R está ausente
           del panel (false positive con Xenium 289/439 genes).
    Fix:   _filter_resource_to_panel() pre-filtra el recurso al panel
           disponible y se pasa al rank_aggregate vía resource=<df>.

Validación numérica (los 3 fixes son robustos para producción):
  Lung AT1 TBD vs control:
    TGFB1   log2FC=2.05  padj=8.2e-70   (inyectado ×3,  recuperado ✓)
    COL1A1  log2FC=1.77  padj=5.6e-51   (inyectado ×2.5, recuperado ✓)
  LIANA detecta ADAM17→MUC1 (hub del piloto cáncer, esperado por
  diseño del panel sintético).

Tiempo total del smoke test: ~16 s (sin scVI).
